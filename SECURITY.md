Reporting a Vulnerability
If you discover a security vulnerability in this project, please follow the steps below to report it responsibly:

Do not create a public issue. Instead, report it privately to avoid exposing the vulnerability before a fix is available.

Email us at: security@example.com

Include:

A detailed description of the vulnerability

Steps to reproduce (if applicable)

Potential impact

Suggested fix (optional but helpful)

We aim to respond within 72 hours of receiving your report. If the issue is confirmed, we will:

Privately discuss a fix and timeline with you.

Credit you in the release notes (optional).

Publish a patched release as soon as possible.

If the vulnerability is invalid or cannot be reproduced, we will notify you with an explanation.

Thank you for helping us keep the project and its users safe!
